# Web Projects｜网页项目合集

网页游戏源码集中在 [games](./games/)，其他互动项目放在 [agent](./agent/)。[任务](./%E4%BB%BB%E5%8A%A1/) 预留给后续任务。

| 十里山路·扛麦挑战（中文版） | 包子和石头每局随机生成，游戏不会自动暂停 | [wheat-mountain-trail](./games/wheat-mountain-trail/) |

| 合成不可说 · 优化版 | 暂停、下一颗预览、单步撤销；手机触控及物理修复 | [suika-the-politician](./games/suika-the-politician/) |
