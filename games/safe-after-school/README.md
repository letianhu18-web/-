# 今天也要平安下班

以使用者提供的 Claude HTML 匯出檔為基礎，保留原作繁體中文案例、引用連結、校園地圖與遊戲規則。

## 使用
直接打開 index.html 即可遊玩。無需安裝依賴或後端。Google Fonts 為可選字體服務，無網路時會使用系統字體。音樂使用 Web Audio 即時合成，朗讀依賴瀏覽器提供的語音。

- 電腦：方向鍵 / WASD 移動；P / Esc 暫停；1–4 選擇事件，Enter 繼續。
- 手機：拖曳校園畫面，或按住左下角方向鍵。
- 切換分頁會暫停，請回到遊戲後按「繼續這一天」。
- 本機儲存遊玩次數、通關紀錄、主題與聲音設定；這些資料不會上傳。
