# 超级马里奥 · 真人主角版

基于 [reruns/mario](https://github.com/reruns/mario) 改编的浏览器平台游戏。主角使用你提供照片中裁切的真人脸部。

## 在线游玩

[打开游戏](https://mario-photo-hero.huheinz.chatgpt.site)

## 关卡

目前有 4 个可选关卡：1-1 草原启程、1-2 地下通道、2-1 云端跳跃、2-2 城堡阶梯。到达旗杆后会自动进入下一关，也可以用页面上方菜单选关。

## 操作

- ← / →：移动
- 长按 ↑ 或 A：跳得更高；轻点也能起跳
- ↓：下蹲或进入管道
- Z / B：奔跑；火焰形态下发射火球

手机屏幕的方向键在左侧，A 和 B 在右侧。横屏时按键会浮在画面两侧，并按屏幕尺寸调整大小。普通移动速度保持原样。

## 本地运行

双击“运行游戏.bat”，或直接在浏览器中打开 `index.html`。
