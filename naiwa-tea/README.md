# 奶蛙奶茶铺 · 优化版

基于 [奶蛙奶茶铺 v0.7.5](https://naiwanaichadian.pages.dev/) 的静态优化版本，版本号 **0.7.9**。原页面署名作者为 **萝卜**；游戏内作者介绍、反馈链接、赞赏入口及二维码已按站点需求移除。

## 开始游戏

本目录包含完整 HTML、CSS、JavaScript、Three.js、角色模型和 18 张服装图片，不依赖原网站加载资源，也不需要构建或安装 npm 包。

安装 Node.js 后，在本目录运行：

```sh
node scripts/serve.mjs
```

打开终端显示的本地地址。需要 HTTP/HTTPS 服务；请不要直接双击 `index.html`，浏览器会限制 ES 模块与模型加载。

## 本次优化

- 新增 **自动 / 清晰 / 省电** 画质选项。自动模式在触屏设备限制渲染分辨率；省电模式使用最多 1 倍像素比与 30 FPS。画质偏好独立保存在当前浏览器中。
- 首页动画限制为 30 FPS，桌面营业可达到 60 FPS；模拟与操作仍按原来的浏览器时钟运行，渲染限速不改变调茶和经营规则。
- 设置等暂停弹窗打开时停止连续 3D 渲染；页面隐藏时停止动画循环，返回后重置计时，避免后台时间影响经营。
- 预加载角色模型。脚本下载失败时显示重试入口；加载较慢时给出提示。
- 支持 WebGL 上下文恢复，提供更明确的 3D 初始化失败提示。
- 微调首页按钮、桌面窗口和小屏布局，补充画质控件的键盘焦点样式。
- 保留经营、装修、服装、熟客故事和存档流程，并增加可重复运行的验证脚本。

## 存档迁移

存档属于浏览器和域名。在原网站的「设置 → 导出存档」保存 JSON，在新地址的「设置 → 导入存档」导入。换域名不会自动带走旧进度。原存档格式和关键存储名称保持兼容。

## 部署

这是静态站点，可将本目录直接部署到 Cloudflare Pages 或其他静态服务，构建命令留空，发布目录使用 `naiwa-tea`（以整个仓库作为根目录时）。

仓库中的 GitHub Actions 会把 `naiwa-tea` 目录发布到 GitHub Pages 网站根路径。当前在线地址是 <https://letianhu18-web.github.io/-/>。每次更新 `naiwa-tea/` 内容都会自动重新发布。

原作者的 Cloudflare 域名由原网站项目管理；向这个 GitHub 仓库发布不会改动该域名。

## 验证

```sh
node scripts/check.mjs
node --test tests/*.test.mjs
```

检查覆盖模块语法、相对导入、静态资源、PNG/GLB 文件有效性，以及渲染计时和存档兼容性。另进行了本地浏览器的手机、桌面和游戏交互验证；具体结果见 `VERIFICATION.md`。
