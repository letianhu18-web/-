# 合成不可说 · Heinz 优化版

基于 [mikotokuroko/suika-the-politician](https://github.com/mikotokuroko/suika-the-politician) 的改进版本。
上游基准提交：`b74e6bd467804f532087c9e71446a97b1af960d5`。

**[在线游玩](https://letianhu18-web.github.io/-/suika-the-politician/)**

## 改进

- 修复一个球在同一物理子步中被多次合成的错误。
- 固定 60 Hz 物理更新，减少不同刷新率下的手感差异。
- 暂停 / 继续、切到后台自动暂停；暂停时停止动画循环。
- 下一颗头像预览；一次投放撤销；重新开始前确认。
- 修复多指、手势取消和无效抬手导致的误投。
- 手机安全区和横屏适配，始终保持棋盘比例；绘制像素比上限 2。
- 最高分实时保存，音效开关保存到浏览器。
- 32 张内置图片统一优化为 WebP，约 17.78 MB → 1.23 MB（减少 93.1%）。
- 不再使用地区定位接口决定是否启动；移除原作者的统计脚本。
- 保留三种内置主题、自定义照片裁剪、配色和中英法语言。

## 操作

手机：拖动瞄准，松手投放。电脑：← / → 瞄准，空格 / ↓ 投放，P / Esc 暂停。
撤销还原上一次投放前的棋盘，只能撤销一步；最高分不会回退。
自定义照片草稿和棋盘进度在刷新时清空；最高分、语言和静音设置保存在当前浏览器。

## 本地运行与验证

无需构建或前端依赖：在此目录执行 `python3 -m http.server 8080`。

`node --test tests/game.test.mjs` 运行游戏逻辑回归测试。
可选分享后端测试：`npm ci && npm test`。

## 照片分享

此版本默认仅在浏览器中处理照片，不上传到原作者服务。
如需公开照片分享，请自行部署 `sharing/worker.js`，并在
`scripts/sharing-config.js` 配置自己的 `SHARING_API`。
Cloudflare 的账户、KV 和允许来源应使用你自己的配置；不要复用原作者的资源 ID。
未配置后端时，保存分享按钮会禁用，自定义主题仍可本地游玩。
