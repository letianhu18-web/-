超级马里奥 · 真人主角版

打开 index.html 即可开始游戏，也可以双击“运行游戏.bat”。

操作（按住方向键即可）：
← / →：移动（原有普通速度）
↑：跳跃
↓：下蹲或进入管道
Z / 屏幕 B：奔跑；火焰形态下发射火球

手机：左侧方向区负责移动、跳跃和下蹲 / 进管道；右侧 A 跳跃，B 奔跑或发射火球。按住即可连续操作。横屏时方向区和动作键分别位于屏幕左右两侧。

主角身体和平台游戏代码来自 GitHub 项目 reruns/mario。
游戏主角脸部使用你提供的第二张照片裁切而成，照片没有改成像素风。
