超级马里奥 · 真人主角版

打开 index.html 即可开始游戏，也可以双击“运行游戏.bat”。

共有 4 个关卡：1-1 草原启程、1-2 地下通道、2-1 云端跳跃、2-2 城堡阶梯。到达旗杆后会自动进入下一关，也可以用页面上方的关卡菜单直接选择。

电脑操作：
← / →：移动
长按 ↑ 或 X：跳得更高；轻点也能起跳
↓：下蹲或进入管道
Z：奔跑；火焰形态下发射火球

手机操作：
左侧方向键：移动、跳跃、下蹲 / 进管道
右侧 A：跳跃，长按会跳得更高
右侧 B：奔跑；火焰形态下发射火球
横屏时方向区和动作键分别位于屏幕左右两侧。页面会根据屏幕尺寸调整按键大小和位置。

方向键移动仍使用普通行走速度；奔跑速度参数没有调整。

主角身体和平台游戏代码来自 GitHub 项目 reruns/mario。
游戏主角脸部使用你提供的第二张照片裁切而成，照片没有改成像素风。
