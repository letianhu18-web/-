# 超级马里奥 · 真人主角版

基于 [reruns/mario](https://github.com/reruns/mario) 的经典平台游戏。主角叠加了用户提供照片裁切出的脸部图像。

## 在线游玩

https://mario-photo-hero.huheinz.chatgpt.site

## 操作

- ← / →：普通速度移动
- ↑：跳跃
- ↓：进入管道；变大后可下蹲

## 本地运行

双击“运行游戏.bat”，或直接在浏览器中打开 `index.html`。
